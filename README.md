## 🎯 What is SF Instant Finder?

SF Instant Finder is a Chrome extension that helps Salesforce Developers and Admins quickly search and open any Salesforce metadata directly from the browser toolbar. No more clicking through Setup menus!

## ✨ Features

- 🔍 **35+ Search Categories** - Search Flows, Apex, LWC, Objects, and much more
- ⚡ **Instant Results** - Search as you type
- 🎯 **Direct Navigation** - Opens results directly in Salesforce Setup
- 💻 **Dev Console Access** - Open Apex Classes in Developer Console with one click
- 🎨 **Beautiful UI** - Clean, modern Salesforce-inspired design
- 🔒 **Secure** - Uses your existing Salesforce session
- 🆓 **100% Free** - No hidden costs

## 🚀 Installation

### From Chrome Web Store (Coming Soon)
Visit the [Chrome Web Store](https://chrome.google.com/webstore) and click Install.

### Manual Installation (Developer Mode)
1. Download this repository as ZIP
2. Extract the ZIP file
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode" (top right)
5. Click "Load unpacked"
6. Select the extracted folder
7. Done! ✅

## 💡 How to Use

1. Open any Salesforce page (Production or Sandbox)
2. Click the SF Instant Finder icon in Chrome toolbar
3. Select what you want to find (Flow, Apex Class, etc.)
4. Type the name (min 2 characters)
5. Click the result → Opens directly in Salesforce!
